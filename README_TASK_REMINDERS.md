# NexusCRM - Phân hệ Nhắc việc & Thông báo Quá hạn

Phân hệ hỗ trợ toàn diện Nhân viên kinh doanh và Trưởng nhóm.

## Điểm nổi bật
- Cấu hình mốc nhắc trước hạn linh hoạt
- Quét định kỳ tự động (Cronjob/Scheduler)
- Báo cáo phân tích nhóm cho Team Leader
- Phân quyền Centralized Data Scope chặt chẽ
- Thông báo thời gian thực qua WebSocket
