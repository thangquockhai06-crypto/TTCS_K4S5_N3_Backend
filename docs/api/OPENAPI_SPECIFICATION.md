# Tài Liệu Đặc Tả Chuẩn OpenAPI 3.0 & Swagger UI

## 1. Giới thiệu
NexusCRM Backend cung cấp toàn diện hệ thống RESTful APIs chuẩn REST Level 2, hỗ trợ xác thực JWT Bearer Token.

## 2. Truy cập tài liệu tương tác
- **Swagger UI**: `http://localhost:8000/docs`
- **ReDoc Interactive**: `http://localhost:8000/redoc`
- **OpenAPI JSON Schema**: `http://localhost:8000/openapi.json`
