# Quy Chuẩn Lập Trình Python PEP8 Chuẩn NexusCRM

1. **Format code**: Sử dụng Black / Flake8 với độ dài dòng tối đa 100 ký tự.
2. **Type Hints**: 100% các hàm trong Service và Repository phải có Type Annotation đầy đủ.
3. **Docstring**: Mô tả rõ ràng mục đích hàm, các tham số đầu vào (args) và giá trị trả về (return).
4. **Pydantic Schemas**: Tách biệt rõ ràng giữa Request Schemas và Response Schemas.
